# Daily Brain
**Smart task assistant that automatically organizes your life into clean categories like School, Business, Work, and Personal.**
---

## ✨ Features
- 🧹 Auto-categorizes tasks using keyword rules  
- 📝 Simple CLI (command-line) interface  
- 📂 Saves categorized tasks to JSON  
- 🔁 Run it daily to keep your life organized  
- 🔧 Easy to extend with new categories or rules
