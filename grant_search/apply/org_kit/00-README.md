# Org kit — Clear Conscience Consulting

The reusable core of every grant application. Per-application drafts copy from
these files and tailor; the canonical fact lives here.

## Before the first submission

Search every file for `[[PLACEHOLDER` and fill it in. The count is deliberate —
these are facts only the organization holds, and none of them may be guessed.
The highest-priority ones, because nearly every funder asks:

1. **UEI** (Unique Entity Identifier from SAM.gov) — required on all federal forms
2. **Board roster** — names, roles, affiliations
3. **Key staff** — names, credentials, FTE
4. **Served numbers** — how many people, over what period
5. **Outcome data** — what changed for them
6. **Budget detail** — the $300,000 broken into revenue and expense lines
7. **Fiscal documents** — most recent 990, audit or review, board-approved budget

## Rule

Never submit a number this kit cannot source. If a funder asks for data the
organization does not track, say so and describe what it does track. Reviewers
routinely forgive a young organization's thin data; they do not forgive
invented data.
